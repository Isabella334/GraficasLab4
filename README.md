# 🪐 Sistema Solar con Shaders Procedurales

Implementación de un sistema solar estilizado en Rust, con shaders procedurales para cada planeta.  
Incluye **Marte**, **Mocca** (inventado), **Saturno** (con anillos), y el **Sol**.
